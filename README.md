# 📌 Project Overview

This repository contains my submission for **Task 2 – Exploratory Data Analysis (EDA) & Business Intelligence** under the **ApexPlanet Data Analytics Internship Program**.

The objective of this task was to explore the cleaned dataset, uncover meaningful business insights using Exploratory Data Analysis (EDA), answer business questions using SQL, and design a static business dashboard highlighting key performance indicators.

# 🎯 Objectives

- Perform Exploratory Data Analysis (EDA)
- Calculate descriptive statistics
- Analyze data distributions
- Answer business questions using SQL
- Discover trends and correlations
